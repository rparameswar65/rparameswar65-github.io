## Question A — How Teachable Machine Uses Machine Learning
Teachable Machine uses transfer learning with MobileNet to classify user-defined categories.

### Process Overview
- **Data Collection**: User provides example images.
- **Feature Extraction**: MobileNet extracts embeddings.
- **Classification Layer Training**: A small classifier is trained.
- **Prediction**: Outputs probability scores.

## Question B — Application Chosen
Car Damage Severity Classifier (Minor, Moderate, Severe) trained with 80+ images/class.
